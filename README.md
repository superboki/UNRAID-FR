# UNRAID-FR Templates

Ce dépôt contient une collection de templates pour des conteneurs Docker sur Unraid, spécifiquement adaptés ou traduits pour la communauté francophone. Ces modèles sont destinés à être utilisés avec le plugin Community Applications (CA) d'Unraid.

## Objectif

L'objectif principal de ce dépôt est de fournir des modèles Unraid en français, facilitant ainsi la configuration et la compréhension des différentes options pour les utilisateurs francophones.

## Modèles Disponibles

Voici la liste des modèles actuellement disponibles dans ce dépôt :

*   **Plex Auto Languages (`plex-auto-languages/`)**: Outil permettant de gérer automatiquement les pistes audio et les sous-titres dans Plex.
*   **PlexTraktSync (`plextractsync/`)**: Synchronise l'historique de visionnage et les évaluations entre Plex et Trakt.tv.
*   **ruTorrent (Crazymax) (`rutorrent-crazymax/`)**: Client BitTorrent basé sur le web (ruTorrent) avec une configuration spécifique (probablement de Crazymax).
*   **Stable Diffusion Advanced (`stable-diffusion-advanced/`)**: Conteneur regroupant plusieurs interfaces et outils pour la génération d'images via Stable Diffusion (Automatic1111, ComfyUI, Fooocus, etc.).

## Utilisation

Pour utiliser ces modèles :

1.  Recherchez l'application souhaitée dans Community Applications.
2.  Installez le conteneur en utilisant le modèle fourni.
